# changelog

마지막 배포 버전(git tag) 이후의 커밋과 서브모듈 변경을 분석해, 사용자 영향도(신기능/버그수정/개선) 기준으로 정리한 CHANGELOG를 채팅에 출력합니다. 파일을 생성하지 않습니다.

## 설치

```
/plugin marketplace add WhiteKr/whitekr-claude-plugins
/plugin install changelog@whitekr-claude-plugins
```

## 사용

```
/changelog                    # 마지막 태그부터 HEAD까지 자동 탐지
/changelog v1.0.7 이후          # 특정 태그 이후로 범위 지정
/changelog 지난주부터            # 자연어 날짜 표현으로 범위 지정
/changelog main 대비            # 브랜치 비교
```

저장소에 태그가 없어 기준점을 자동으로 찾지 못하면, 비교 기준을 직접 물어봅니다.

## 동작

- **두 시점 사이의 최종 diff를 기준으로 기록**합니다. 범위 중간에 추가됐다가 되돌려진 변경은 언급하지 않고, 여러 번 수정을 거친 기능도 그 과정이 아니라 최종 모습만 하나의 항목으로 서술합니다.
- 커밋을 사용자 영향도 기준(신기능/버그수정/개선/기타)으로 분류해 정리합니다.
- 커밋 메시지 나열이 아니라, 실제 diff 내용을 근거로 무엇이 바뀌었는지 서술합니다.
- 서브모듈 gitlink가 바뀐 경우 해당 서브모듈 내부 커밋까지 확인해, 프로젝트에 영향이 있으면 "서브모듈 업데이트" 섹션에 간단히 표시하고 내부 정리성 변경뿐이면 노이즈로 제외합니다.
- "기타" 항목을 포함해 최종 diff에 남은 변경은 임의로 추리거나 요약하지 않고 전부 나열합니다.
- 출력 언어는 대화가 진행 중인 언어를 따릅니다.

## 호환성

`scripts/collect-changes.sh`는 표준 git과 POSIX bash에 의존하며 Linux / macOS / WSL에서 동작합니다.
